# ☕ Velvet & Leaf - Artisan Coffee & Botanical Tea Lounge

A modern, responsive Coffee & Tea Cafe Web Application featuring:
- **Authentication**: Login, Registration, Password Visibility Toggle, "Remember Me", and 1-Click Quick Demo Login.
- **Cafe Dashboard**: Dynamic time-based greetings (*Good Morning ☕ / Afternoon 🍵*), live loyalty points, stamp card rewards.
- **Menu & Filtering**: Filter by *Coffee*, *Special Tea*, and *Bakery & Snacks*.
- **Interactive Cart & Checkout**: Real-time floating cart bar, slide-up cart drawer, quantity adjusters, and order confirmation.
- **Zero External Dependencies**: Pure HTML5, CSS3, JavaScript, and a lightweight Node.js server.

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone <YOUR-REPOSITORY-URL>
   cd cafe-tea-web
   ```

2. Start the local server:
   ```bash
   node server.js
   ```

3. Open in your browser:
   **http://localhost:8080**
